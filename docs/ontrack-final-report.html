Phạm vi đã thực hiện

  • Fetch và merge các commit FE mới từ origin/master (đến 5e79d20) vào nhánh BE hiện tại, đồng thời lưu lại trạng thái trước merge trong git stash.
  • Giữ FastAPI/PostgreSQL REST API v3 làm backend; không đưa Supabase secret vào app mobile.
  • Đưa các màn hình FE mới: deadline, milestone, task, session, lịch sử và cài đặt vào workspace.
  • Nối tab Plans với GET /api/v3/deadlines; chuyển dữ liệu API thành card UI, lọc/tìm kiếm trên dữ liệu thật và mở chi tiết bằng ID thật.
  • Nối tab Today với GET /api/v3/dashboard/today; hiển thị session kế tiếp, session còn lại, session hoàn thành và risk card từ BE.
  • Chuẩn hóa các route FE cũ để Expo Router typecheck được với cấu trúc file hiện tại.
  • Thêm unit test cho adapter deadline → Plans card.

Kết quả E2E trên web local

PASS Chạy trên http://127.0.0.1:8081 với PostgreSQL và FastAPI local.

  1. Đăng ký tài khoản E2E mới và được chuyển đến Today.
  2. Tạo Deadline từ form FE; deadline xuất hiện lại trong Plans từ API thật.
  3. Tạo Milestone và Task trong Deadline Detail.
  4. Tạo, start Focus Session, end early và lưu Review.
  5. Xác minh DB: session ENDED_EARLY, progress task/review = 40, actual minutes = 20.
  6. Browser console không có lỗi mức error.

Trong quá trình E2E đã phát hiện màn Create Deadline ban đầu chỉ hiển thị thông báo thành công. Màn này đã được sửa để gọi POST /api/v3/deadlines và xác minh lại bằng UI.

Hướng dẫn chạy lại

  1. Mở Docker Desktop.
  2. Từ root chạy docker compose up -d postgres.
  3. Từ backend chạy .\.venv\Scripts\python -m uvicorn app.main:app --port 8000.
  4. Đặt EXPO_PUBLIC_API_URL=http://<IP-LAN-máy-BE>:8000 khi chạy trên thiết bị thật (không dùng localhost của máy tính).
  5. Đăng ký một tài khoản mới và kiểm tra chuỗi Deadline → Milestone → Task → Session → Start/End → Review.
